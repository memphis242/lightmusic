Bluetooth default-sink check - little-forge, 2026-10-29 (~04:13-04:16 -05:00)
Question: during the 03:35 bench run the BT headset was connected and default sink was
bluez_output.XX_XX_XX_XX_XX_XX.1, yet miniaudio reported "Built-in Audio Analog Stereo". Which output does it pick?

ANSWER: miniaudio follows the server default correctly. The headset dropped off during the bench run.

Root cause (timeline from the journal):
  03:35:49  bench report records "Default Sink: bluez_output.XX_XX_XX_XX_XX_XX.1"
  03:36:04  gsd-media-keys: "Unable to get default sink" / "Unable to get default source" (the default sink disappeared, during the build step)
  ~03:38    2b/2c playback opens the default device -> only the built-in sink is left -> "Built-in Audio Analog Stereo".
            The report's internal_format=32-bit Signed Integer matches the built-in sink (s32le), not the BT sink (s16le),
            so the stream really ran on the built-in sink; the name is not a mislabel. The built-in sink is MUTED (wpctl vol 0.60 MUTED), so that playback was silent.
  04:10:57  kernel: "input: soundcore Q20i (AVRCP)" -> the headset reconnects (the BT sink index is now 619)
  There is no explicit disconnect line in the journal (bluetoothd logs nothing); the drop is inferred from the 03:36:04 message, the s32 format and the 04:10:57 reconnect.

miniaudio code path (third_party/miniaudio.h 0.11.21, ma_device_init__pulse):
  default device -> pDeviceID == NULL -> devPlayback = NULL
  -> pa_context_get_sink_info_by_name(NULL) (the server default; gives the sample spec)
  -> pa_stream_connect_playback(stream, NULL, ...) with no DONT_MOVE flag (the server routes the stream and it can follow default changes).
  An explicit device id sets MA_PA_STREAM_DONT_MOVE (pactl shows node.dont-reconnect=true and target.object=<id>).
  miniaudio never substitutes a sink name of its own for the default.

Bench changes in this commit:
  - src/devlist.cpp: new probe that lists playback devices (id, name, isDefault) for the PulseAudio and ALSA backends.
  - src/play.cpp: "--dev SPEC" (isdefault | id/name substring) for an explicit device, and a

  - run.sh 2b: logs `pactl get-default-sink` right before playback.
